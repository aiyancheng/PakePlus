## 三、优化原则（执行约束）

1. **对齐手册、补漏纠偏**：以手册标准动作为准，不改写手册；课程侧补齐参数、动作、话术，修正冲突表述。
2. **篇幅不缩水**：保持每天约 2.2 万字量级，新增内容以「与手册一致的参数表 / 双栏动作-话术」形式嵌入。
3. **结构对齐**：课程章节顺序尽量与手册一致，便于「学完课程 → 翻手册对照」。
4. **样式不新增体系**：沿用各文件既有 CSS 类（section / highlight-box / table 等），不引入新设计语言。
5. **练习题同步**：题干与答案必须与优化后的学习内容一致，覆盖手册核心参数与易错点。
